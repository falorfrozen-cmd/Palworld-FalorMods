# Falor's QoL Pack

Twelve quality-of-life mods in one package. Every mod has
its own page in Esc > Mod Options with an on/off switch.

Unlock All Waypoints, Unlock All Technology, Unlock All Blueprints, Boss Respawn, Big Inventory,
Global Base Storage, Pickup Boost, Fast Breeding, Speed Boost, Time of Day,
Teleport to Player, Salvage With Any Pal, plus data tweaks (instant Palbox
recovery, better grappling gun, 100x medicine crafting, Red Berries at the
Breeding Farm).

Required (Steam Workshop): UE4SS Experimental (Palworld), PalSchema,
Mod Options Framework, Passive Transfer.

Most mods run on the world host. Dedicated servers are not supported.
Unlocks and pouches are written into the save; removing the pack does not
undo them.

The settings pages use the SDK of Mod Options Framework by Elv (MIT
license); the license text is next to the SDK files.
